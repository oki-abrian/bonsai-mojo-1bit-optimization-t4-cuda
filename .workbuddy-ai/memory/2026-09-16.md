Bukti (uji lokal dipakai HANYA sebagai pembuktian mekanisme — build sesungguhnya
tetap di Kaggle):

- `mojo build --target-accelerator=sm_75` -> SUKSES tanpa hardware NVIDIA;
  biner hasilnya memuat `.target sm_75` = codegen PTX NVIDIA benar-benar jalan.
- Nilai salah (`cuda:sm_75`, `bogus_accel`) -> gagal dengan **signature SAMA**
  seperti di Kaggle CPU: `function instantiation failed` + `failed to run the
  pass manager`. Jadi arch `''` = "accelerator tidak dispesifikasikan".
- Format nilai = arch telanjang: `sm_75` (BUKAN `cuda:sm_75`).
- `nvcc` TIDAK relevan untuk `mojo build` (Mojo pakai backend NVPTX sendiri).
- Rute config-file TIDAK jalan: `mojoproject.toml` berisi `[build]` dengan
  `target-accelerator` / `gpu-arch` / `accelerator` (masing-masing diisi nilai
  bogus sebagai diskriminator) tetap SUKSES -> key itu DIABAIKAN `mojo build`.
- Tidak ada env var: grep binary tidak menemukan `MOJO_*`/`MODULAR_*` bertema
  ACCEL/GPU_ARCH.

### Perbaikan minimal (BUTUH IZIN — mengedit skrip terbukti)
