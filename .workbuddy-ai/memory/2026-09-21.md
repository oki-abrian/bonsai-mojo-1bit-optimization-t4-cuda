   kernel_sources (`okiabrian/bonsai-mojo-t4-build`) selain kernel CPU.
   SEBAB: rantai cache = output kernel CPU -> input kernel GPU, dan output
   run GPU TIDAK pernah dipakai lagi (kernel CPU menyumber dirinya sendiri).
   Tanpa ini, cache kv_dump.bin yang ditulis run GPU akan selalu hilang.
   Impor di deploy_on_kaggle.sh dari /kaggle/input/bonsai-mojo-t4-build/
