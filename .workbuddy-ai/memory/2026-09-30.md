## Perbaikan deterministik: RTLD.NODELETE di try_open_cuda_lib (src/ops.mojo)

- Edit (diizinkan alur perbaikan): `from sys.ffi import OwnedDLHandle, RTLD`; semua 5 konstruksi `OwnedDLHandle(...)` di `try_open_cuda_lib()` kini pakai `RTLD.NOW | RTLD.GLOBAL | RTLD.NODELETE` via `alias _RTLD_FLAGS`. Docstring `khq_state_slot_cell` dikoreksi (klaim lama terbukti keliru).
- Prinsip: dengan RTLD_NODELETE, dlclose tak PERNAH melepas pemetaan .so → urutan kodegen tak lagi relevan → kelas bug ini mati untuk SEMUA titik FFI. Biaya: .so 2,4 MB menetap terpetakan.
